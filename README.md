# Project Name

**Data-Driven Surveillance: Lassa Fever Forecasting for Public Health Action**  

## Description

This project focuses on forecasting weekly Lassa fever cases in Nigeria using publicly available data from the Nigeria Centre for Disease Control (NCDC) from 2020 to 2025. By applying time-series analysis and machine learning models, the project aims to:

-   Predict future Lassa fever trends to support public health preparedness.
    
-   Provide actionable insights for outbreak response and resource allocation.
    
-   Demonstrate reproducible methods for disease surveillance using open-source tools.
    

The repository includes:

-   Data preprocessing scripts (extracting, cleaning, and aggregating weekly case data)
    
-   Exploratory data analysis and visualization
    
-   Time-series forecasting models
    
-   Evaluation metrics and results
